挑選單元組課

從資料夾開啟時無法組課，請先在專案資料夾執行 node scripts/preview.cjs，再開啟本機組課工具。

改寫主題進階換成自己的情境，程式概念與評量不變。

需能修改檔案的 AI 工具，例如 OpenAI Codex、Claude Code，或已連結專案資料夾的 Claude 桌面應用程式；預覽與檢查需安裝 Node.js。

  1. 下載並解壓縮。確認 README 標示 V-2。下載原始碼 ZIP ↗
  2. 開啟專案資料夾。在 AI 工具中選擇含有 index.html 與 package.json 的整個資料夾。
  3. 貼上改寫指令。把「海洋探索」換成你的主題，ocean 換成簡短英文代碼。
  4. 預覽並檢查。執行 node scripts/preview.cjs，開啟本機預覽核對教材。
