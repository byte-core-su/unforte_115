# unforte_115

互動式程式設計教材網站，提供七、八年級 Scratch 課程、Python 引導式學習、Scratch 範例教材與教師資源圖解。

> 想從零建立一套相同類型的教材網站，請閱讀[從零復刻教材系統：新手開發手冊](SYSTEM_REPLICATION_GUIDE.md)；想了解本網站如何從課程整理、教材設計調整到目前定位，可閱讀[系統開發過程](DEVELOPMENT.md)；要新增或復刻單一教材單元時，請參考[新增教材單元指南](UNIT_AUTHORING_GUIDE.md)。

授課規劃可在網站閱讀[七年級教案](lesson-plan-grade-7.html)與[八年級教案](lesson-plan-grade-8.html)，也可參考[108 課綱逐課對照](CURRICULUM_ALIGNMENT.md)與可列印的[學生學習紀錄表](STUDENT_RECORDS.md)。兩份教案各為六單元、建議 12 節的主題教材，不代表已涵蓋各年級全學年的課程。教案的 Markdown 原始檔仍為 `LESSON_PLAN_GRADE_7.md`、`LESSON_PLAN_GRADE_8.md`；修改後執行 `npm install` 與 `npm run build:lesson-plans`，即可更新對應 HTML 頁面。

## 課程內容

- **11507 課程**：程式流程、畫筆與幾何圖形、重複結構、變數、資訊安全與資料處理應用；自訂積木與參數為進階延伸。
- **11508 課程**：清單、音樂、資料處理、搜尋、排序、隨機與模組化，採用任務、模擬和 Scratch 實作進行練習。
- 每組課程均有 6 個互動單元；活動包含概念說明、積木排序、即時模擬與小測驗。

## 七年級課程：星際防禦工程師

七年級以 Scratch 的核心程式思維為主，從讀懂積木、預測程式結果開始，逐步建立迴圈、變數與自訂積木的抽象能力，最後完成可測試的互動專題。

| 單元 | 主題 | 核心學習 |
| --- | --- | --- |
| 1 | 起步診斷：讀懂積木 | 辨識事件、動作、控制與變數積木，建立 Scratch 操作基礎。 |
| 2 | 程式三大結構 | 用循序、選擇、重複描述程式，練習預測、執行與除錯。 |
| 3 | 迴圈多邊形 | 以重複執行與轉角規律繪製正多邊形。 |
| 4 | 變數螺旋圖騰 | 追蹤變數的初始值與更新規則，控制圖形變化。 |
| 5 | 幾何曼陀羅 | 複習迴圈與變數；自訂積木和參數為進階體驗。 |
| 6 | 防禦網與資料應用 | 測試防禦網參數，搜尋與比較資料，選出有效且省資源的方案。 |

## 八年級課程：星際陣列指揮官

八年級以 Scratch 清單為資料結構主軸。每課強調「執行前、執行中、執行後」的資料追蹤，讓學生不只會操作積木，也能說明演算法步驟與驗證結果。

| 單元 | 主題 | 核心學習 |
| --- | --- | --- |
| 1 | 星艦資料庫基礎 | 新增、插入、替換、刪除、讀取、索引值與循序搜尋。 |
| 2 | 星際通訊 | 依索引走訪音符清單，將資料轉成旋律，討論錄音與素材授權。 |
| 3 | 能源庫存分析 | 以可編輯清單計算總和與平均，測試多筆、單筆、空清單。 |
| 4 | 招募先遣隊 | 透過候選與已選清單，完成不重複的隨機抽取。 |
| 5 | 武器庫洗牌 | 比較洗牌與相鄰比較排序，追蹤資料變化與停止條件。 |
| 6 | 星際爭霸戰 | 以自訂積木分工建立、洗牌、分配與逐回合對決，完成三組測試。 |

## 課程活動結構

每個單元均提供課程學習導航，採用下列節奏：

1. 情境任務與本課目標
2. 概念示範與引導練習
3. 獨立挑戰：動手完成 Scratch 任務
4. 成果證據：作品、程式說明或資料追蹤表
5. 離堂檢核：用自己的話解釋規則、結果或除錯方式

七、八年級全部 12 課另有頁末「本課自適應練習」：基礎、標準、挑戰三級可自行選擇；同一題首次答錯會給提示，同題第二次仍答錯會顯示詳解並降低下一題難度；連續兩道新題首次答對則提高難度。題目依各課概念重新產生，跳題不算通過，也不鎖住課程。這是規則式的形成性練習，不是 AI 評分或正式成績；作答狀態只存在當前頁面，重新整理即清除，不傳送或保存學生資料。正式評量仍依教案的四級規準，檢視 Scratch 作品、資料追蹤和修正說明。

反覆練習時，七年級第 2～6 課的數值實驗、幾何參數與資料分析，以及八年級第 1、3、5 課的清單、加總、搜尋與排序練習，會在進入流程時產生新案例，並可再次產生或切換固定示範。八年級第 2 課保留與 Scratch 任務一致的《小星星》示範，另可按「再抽一首」練習其他旋律；第 4～6 課的抽籤、洗牌與對決原本就會產生隨機結果。概念題、積木正確流程與教學用公式不隨機更改，避免題意或答案失準。

自適應練習另提供可開關的「專注作答模式」，預設關閉。開啟後，離開分頁或切換視窗滿 3 秒，返回時會更換尚未按過「檢查預測」的題目並清除選擇，維持難度與連續答對紀錄，不扣分；已檢查的題目保留提示或詳解，方便訂正。模式僅作用於頁末自適應練習，不影響課程活動；需要切到 Scratch 或查資料時可先關閉。開關狀態與離開時間不保存、不傳送；此功能只是專注提醒，不能可靠防止網頁猴等工具，也不能作為作弊判定依據。

## 使用方式

直接以瀏覽器開啟 `index.html`，或部署至靜態網站服務（例如 GitHub Pages）。教材頁面可離線瀏覽，但外部 CDN 的字型與樣式需要網路連線。

CodeGame 點亮任務保存在 `codegame/`，可開啟 `codegame/index.html`，或在本機預覽開啟 `http://127.0.0.1:4173/codegame/`。它是自行開發的機器人指令解謎遊戲，逐關重現指定 Lightbot Code Hour 保存版本的 20 關地圖、高度、起點、方向與指令容量。支援前進、轉向、跳躍、點燈、P1/P2 程序、遞迴迴圈、單步執行與通關判定。原版嵌入頁保留在 `codegame/lightbot.html`。

學生姓名、學號、班級顯示在遊戲上方；草稿、通關、最佳指令、嘗試次數與學習時間依班級及學號保存於此瀏覽器，重新整理後可繼續練習。可下載包含學生資料、遊戲狀態及指令的 PNG，或匯出學習紀錄 JSON。尚未提供登入驗證與資料庫同步。後續可透過 `window.LightbotLearning.setStudent(...)` 更新學生，透過 `exportData()` 及 `codegame:progress` 事件取得紀錄；詳細規則、來源與資料介面見 [CodeGame 說明](codegame/README.md)。

Python Lab 是獨立課程，直接以其網站網址開啟，與原教材首頁不互相導連。可將 `pythonlab/` 單獨部署；本機執行 `npm run preview`（或 `node scripts/preview.cjs`）後，開啟 `http://127.0.0.1:4173/pythonlab/index.html`。Python 執行環境固定使用 Pyodide 0.27.7，首次載入需網路。草稿、預測、離堂說明與挑戰驗證只保存在此瀏覽器，不跨裝置同步。詳細教學流程與維護方式見 [Python Lab 說明](pythonlab/README.md)，課程規劃見 [Python 課程設計](PYTHON_COURSE_PLAN.md)。

Python 的十二個單元依序為輸出、變數與輸入、型態與運算、條件、for 累加、巢狀迴圈、while、清單、函式與模組、購物結帳專題、資料排序、字典票選統計。每課包含示範、引導、初階一星、進階二星與選做終極三星，以及語法卡、逐層提示與離堂檢核。一星允許參考完整解答，二星需修改規則並通過新測資，完成核心學習；三星不強制。既有通過紀錄保留為一星。

## 技術概況

- 靜態 HTML、CSS、原生 JavaScript 為主
- 使用 Tailwind CSS、Lucide、Font Awesome 等 CDN 資源
- `1150801.html` 使用 React 與 Babel 的瀏覽器端版本
- `learning-guides.js` 顯示逐課目標與完成證據；`curriculum-labs.js` 提供課綱補強互動活動；`adaptive-practice.js` 提供不保存作答資料的三級自適應練習
- 僅七年級第 1、2 課部分通關狀態以瀏覽器 `localStorage` 保存；網站不記錄全站成績，也沒有作業繳交後端
- Python Lab 另以 `localStorage` 保存自身的練習草稿與挑戰驗證；Python 在可停止的 Worker 執行，每次任務使用新的變數命名空間，限制執行時間與輸出量，並提供多組案例驗證。這些是形成性練習，不是正式評分或安全隔離服務。
