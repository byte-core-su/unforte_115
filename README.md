# unforte_115

以 Scratch 為主的互動式程式設計教學網站，包含兩組課程、Scratch 範例教材，以及供教師批改與學生繳交作業使用的頁面。

## 課程內容

- **11507 課程**：程式流程、畫筆與幾何圖形、重複結構、變數、函式與參數等 Scratch 核心概念。
- **11508 課程**：清單、音樂、資料處理、隨機與排序等延伸主題，採用任務與模擬方式進行練習。
- 每組課程均有 6 個互動單元；活動包含概念說明、積木排序、即時模擬與小測驗。

## 七年級課程：星際防禦工程師

七年級以 Scratch 的核心程式思維為主，從讀懂積木、預測程式結果開始，逐步建立迴圈、變數與自訂積木的抽象能力，最後完成可測試的互動專題。

| 單元 | 主題 | 核心學習 |
| --- | --- | --- |
| 1 | 起步診斷：讀懂積木 | 辨識事件、動作、控制與變數積木，建立 Scratch 操作基礎。 |
| 2 | 程式三大結構 | 用循序、選擇、重複描述程式，練習預測、執行與除錯。 |
| 3 | 迴圈多邊形 | 以重複執行與轉角規律繪製正多邊形。 |
| 4 | 變數螺旋圖騰 | 追蹤變數的初始值與更新規則，控制圖形變化。 |
| 5 | 幾何曼陀羅 | 以自訂積木與參數封裝重複工作，產生不同圖形。 |
| 6 | 防禦系統專題 | 整合事件、迴圈、變數與自訂積木，完成並測試互動作品。 |

## 八年級課程：星際陣列指揮官

八年級以 Scratch 清單為資料結構主軸。每課強調「執行前、執行中、執行後」的資料追蹤，讓學生不只會操作積木，也能說明演算法步驟與驗證結果。

| 單元 | 主題 | 核心學習 |
| --- | --- | --- |
| 1 | 星艦資料庫基礎 | 新增、插入、替換、刪除、讀取與索引值。 |
| 2 | 星際通訊 | 依索引走訪音符清單，將資料順序轉成旋律。 |
| 3 | 能源庫存分析 | 用累加器與清單走訪計算總和與平均，練習邊界案例。 |
| 4 | 招募先遣隊 | 透過候選與已選清單，完成不重複的隨機抽取。 |
| 5 | 武器庫洗牌 | 追蹤資料移轉、隨機索引與洗牌演算法的不變條件。 |
| 6 | 星際爭霸戰 | 整合清單、隨機與資料更新，完成有測試案例的遊戲專題。 |

## 課程活動結構

每個單元均提供課程學習導航，採用下列節奏：

1. 情境任務與本課目標
2. 概念示範與引導練習
3. 獨立挑戰：動手完成 Scratch 任務
4. 成果證據：作品、程式說明或資料追蹤表
5. 離堂檢核：用自己的話解釋規則、結果或除錯方式

## 使用方式

直接以瀏覽器開啟 `index.html`，或部署至靜態網站服務（例如 GitHub Pages）。教材頁面可離線瀏覽，但外部 CDN 的圖示與樣式需要網路連線。

教師與學生批改功能另外依賴外部批改 API、Google Apps Script、Google Classroom 與 Google Drive 授權；這些後端服務不包含在本倉庫中。

## 技術概況

- 靜態 HTML、CSS、原生 JavaScript 為主
- 使用 Tailwind CSS、Lucide、Font Awesome 等 CDN 資源
- `1150801.html` 使用 React 與 Babel 的瀏覽器端版本
- 學習活動進度以瀏覽器 `localStorage` 保存
