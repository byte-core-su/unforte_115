# 資訊科技課程教材｜V-2

互動式程式設計教材網站，提供七、八年級積木程式課程、Python 引導式學習、積木程式模擬器與教師資源。

**目前外層工作版本為 V-2，七、八年級積木程式教材使用星際主題。** 上課首頁提供 七年級積木程式、八年級積木程式、CodeGame、Python Lab 四門課的入口。教案、範例、學習紀錄及示範模式集中在[教師備課](teacher-resources.html)。各單元的課名、目標、必交項目與達標條件由同一份資料維護。詳見[課程模組維護指南](MODULES_GUIDE.md)。

| 版本 | 位置 | 用途 |
| --- | --- | --- |
| V-1 | `V-1/`（只在本機，不推送到 GitHub） | 修改前的完整備份，保留原始檔及 SHA-256 清單；已列入 `.gitignore`。 |
| V-2 | 專案根目錄，即本 README 所在資料夾 | 持續修改的版本，包含課程地圖與主題改編說明；無須另外建立 `V-2/`。 |

## 下載與開始使用

1. 開啟[原始碼專案](https://github.com/byte-core-su/unforte_115)，選擇 **Code → Download ZIP**，或使用[下載主分支 ZIP](https://github.com/byte-core-su/unforte_115/archive/refs/heads/main.zip)。下載的是 GitHub 當時的版本；下載後先確認本 README 標示 **V-2**，尚未推送的本機修改不會包含在下載包內。
2. 完整解壓縮，再開啟資料夾內的 `index.html`。首頁先選課程；進入七、八年級課程總覽後，可從「課程單元導覽」選單元開始上課。需要看單元之間的關聯時，從「教師備課」開啟「課程地圖」，可切換年級，以及「概念關聯圖」「成果卡片」兩種檢視。每個單元頁上方有「教師備課：本課教案」連結，可直接跳到該課的兩節課安排。需要更換主題時，請參考下方的主題改編說明。直接從資料夾開啟時，可使用積木程式教材、教案與學習紀錄。Python Lab 請透過網站或本機預覽開啟。
3. 使用 Python Lab 時，請從網站網址或本機預覽開啟。本機先安裝 [Node.js](https://nodejs.org/)，在**解壓縮後、含有 `package.json` 的資料夾**開啟終端機，執行：

   ```sh
   node scripts/preview.cjs
   ```

4. 開啟 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。終端機需保持開啟；結束預覽時按 `Ctrl+C`。預覽本身不需先執行 `npm install`。

若要保留自己的修改歷程，可先在 GitHub Fork 成自己的專案再下載或 clone。ZIP 下載不含 Git 歷程；也不要在壓縮檔預覽視窗內直接編輯。

## 用 AI 工具快速更換星際主題

需要能修改檔案的 AI 工具，例如 OpenAI Codex、Claude Code，或已連結專案資料夾的 Claude 桌面應用程式；預覽與檢查另需安裝 Node.js。先將**整個專案資料夾**開啟為可讀寫的工作專案，再貼上指令。只在一般聊天視窗描述需求，不能直接修改電腦裡的檔案。熟悉程式的教師也可以不用 AI 工具，依[課程情境切換指南](COURSE_SCENARIOS_GUIDE.md)直接修改 `course-scenarios.js`。

| 工具 | 開始方式 |
| --- | --- |
| OpenAI Codex | 在 Codex App 或編輯器的 Codex 擴充功能中，開啟解壓縮後的整個資料夾，再貼上以下指令。 |
| Claude Code | 在可選擇本機專案的介面中開啟同一資料夾；已安裝 CLI 的使用者也可在此資料夾的終端機執行 `claude`，再貼上指令。 |
| Claude 桌面應用程式 | 在對話中連結解壓縮後的整個資料夾，確認 Claude 可以讀寫其中的檔案，再貼上指令。 |

### 方法一：快速更換情境文字與資料

把下列指令中的 `【海洋探索】` 改成自己想要的主題，例如校園生活、森林探險、城市交通或在地文化，就能開始。這種做法先處理共用情境，適合快速試看主題；動畫、圖片及積木程式仍可能保留星際素材。

```text
請直接修改目前的 V-2 課程，將七、八年級積木程式課程改成【海洋探索】主題。
先閱讀 README.md、COURSE_SCENARIOS_GUIDE.md、MODULES_GUIDE.md 與 course-scenarios.js。
請自行擬定適合國中生的角色、七八年級課名、每課任務、清單項目及專題名稱，然後完成修改。
優先在 course-scenarios.js 新增完整的 ocean 情境並設為 activeId，保留 space 可切回。
逐層定義 grades、briefing、cards、inventory、defense、statistics、duel，保留識別鍵與資料規則。
同步更新首頁、課程地圖、模組目錄、學習導航中有涉及情境的文字及 HTML 備援內容。
保留 12 個模組 ID、入口路徑、課號順序、學習目標、演算法與判分結果，僅調整故事與資料名稱。
不改 V-1；Python Lab、CodeGame 與歷史文件維持原樣。
此步先不修改圖片、語音或網頁動畫，請在完成說明列出仍保留舊素材的位置。
執行既有測試與資源檢查；測試若綁定星際文字，確認是文案差異後才更新對應文字斷言，保留功能驗證。
最後提供預覽方式、修改清單、仍需同步的素材，以及如何切回 space。
```

`ocean` 是這個範例的情境代碼；若選其他主題，請一併改成簡短英文字，例如 `campus` 或 `forest`。新增情境後，仍須登錄相應的課程資源，不能只新增名稱就宣稱教材已全數同步。

### 方法二：連同整套教材改編

若希望學生從網頁、動畫到教案都看到同一主題，使用下列版本。把括號改成需求；未指定的細節可交由工具依課程概念安排。

```text
請將目前 V-2 七、八年級積木程式課程完整改編為以下主題，並直接實作：
主題：【海洋探索】
對象：【國中七、八年級】
角色：【海洋觀測站的程式設計團隊】
視覺：【藍綠、明亮、易閱讀；圖卡搭配少量任務動畫】
範圍：【首頁、分年級課程地圖、12 個積木程式模組、單元網頁、教案、學習紀錄、課綱對照、當前教學簡報及 網頁積木程式模擬器】
先讀 README.md、MODULES_GUIDE.md、COURSE_SCENARIOS_GUIDE.md、COURSE_MATERIALS_GUIDE.md。
先整理「原星際情境 → 新情境 → 保留的程式概念」對照，再接續完成實作。
保留 V-1、space 原設定、模組 ID、學習目標、操作邏輯、測試規則與評量規準；Python Lab、CodeGame 和歷史開發紀錄不在改編範圍。
新主題需合理對應各課：七年級以幾何與參數測試為主；八年級維持清單、音符、統計、不重複抽取、洗牌排序及四個自訂積木的分工。
共用設定、未接入設定的文案、圖示、動畫標籤、HTML 備援、模組說明、下載路徑及課程資料需一致。
同步修改網頁模擬器的角色、變數、清單與測試資料，保留程式行為，並更新對應的教案與紀錄表。
教案 Markdown 修改後重建對應 HTML；檢查課程地圖及前後導覽。
執行 npm test 與 npm run check:materials；在瀏覽器驗證改過的互動與積木程式。
如有缺少原始素材或無法執行的工具，先完成可修改的部分，具體列出限制與待辦，不要把未同步的資源標成完成。
完成後提供修改摘要、檢查結果與預覽入口。
```

## 修改後如何檢查

在專案根目錄執行；Windows 若 PowerShell 阻擋 `npm.ps1`，可將下列 `npm` 改成 `npm.cmd`。

```sh
npm install
npm test
npm run check:materials
```

修改教案、課綱對照或學習紀錄的 Markdown 時，另執行 `npm run build:lesson-plans`。瀏覽器至少試走：首頁課程入口、兩個年級的課程地圖、前後單元導覽及被修改的單元操作。資源檢查只檢查已登錄的項目，不能取代整套教材的人工核對。

## 課程內容

- **11507 課程**：程式流程、畫筆與幾何圖形、重複結構、變數、資訊安全與資料處理應用；自訂積木與參數為進階延伸。
- **11508 課程**：清單、音樂、資料處理、搜尋、排序、隨機與模組化，採用任務、模擬和網頁積木程式練習。
- 每組課程均有 6 個互動單元；活動包含概念說明、積木排序、即時模擬與小測驗。

## 七年級課程：星際防禦工程師

七年級以積木程式的核心程式思維為主，從讀懂積木、預測程式結果開始，逐步建立迴圈、變數與自訂積木的抽象能力，最後完成可測試的互動專題。

| 單元 | 主題 | 核心學習 |
| --- | --- | --- |
| 1 | 起步診斷：讀懂積木 | 辨識事件、動作、控制與變數積木，建立積木程式操作基礎。 |
| 2 | 程式三大結構 | 用循序、選擇、重複描述程式，練習預測、執行與除錯。 |
| 3 | 迴圈多邊形 | 以重複執行與轉角規律繪製正多邊形。 |
| 4 | 變數螺旋圖騰 | 追蹤變數的初始值與更新規則，控制圖形變化。 |
| 5 | 幾何曼陀羅 | 複習迴圈與變數；自訂積木和參數為進階體驗。 |
| 6 | 參數測試與資料應用（星際任務：防禦網） | 測試防禦網參數，搜尋與比較資料，選出有效且省資源的方案。 |

## 八年級課程：星際陣列指揮官

八年級以 清單為資料結構主軸。每課強調「執行前、執行中、執行後」的資料追蹤，讓學生不只會操作積木，也能說明演算法步驟與驗證結果。

| 單元 | 課程地圖名稱（星際任務） | 核心學習 |
| --- | --- | --- |
| 1 | 清單基本操作與搜尋（星艦資料庫基礎） | 新增、插入、替換、刪除、讀取、索引值與循序搜尋。 |
| 2 | 音符清單與索引走訪（星際通訊） | 依索引走訪音符清單，將資料轉成旋律，討論錄音與素材授權。 |
| 3 | 清單統計：總和與平均（能源庫存分析） | 以可編輯清單計算總和與平均，測試多筆、單筆、空清單。 |
| 4 | 不重複的隨機抽取（招募先遣隊） | 透過候選與已選清單，完成不重複的隨機抽取。 |
| 5 | 洗牌與相鄰比較排序（武器庫洗牌） | 比較洗牌與相鄰比較排序，追蹤資料變化與停止條件。 |
| 6 | 自訂積木與清單專題（星際爭霸戰） | 以自訂積木分工建立、洗牌、分配與逐回合對決，完成三組測試。 |

課程地圖與 `modules/` 使用括號前的概念名稱；教案標題與單元頁使用括號內的星際任務名稱。

## 課程活動結構

每個單元均提供課程學習導航，採用下列節奏：

1. 情境任務與本課目標
2. 概念示範與引導練習
3. 獨立挑戰：在模擬器組裝並執行積木程式
4. 成果證據：作品、程式說明或資料追蹤表
5. 離堂檢核：用自己的話解釋規則、結果或除錯方式

### 學習路線引導（單一路線、依序解鎖）

12 個積木程式單元都在原頁依序顯示活動。**認識任務 → 網頁上的活動 → 積木程式模擬器實作 → 換題練習 → 離堂任務**。每課可在模擬器排積木、執行與修正，並按「複製程式與結果」留下紀錄。

- **依序解鎖**：學生勾完這一步的「完成標準」，按「完成這一步」才會開啟下一步。紀錄表在需要填寫的步驟開啟。「前往下一單元」在完成本課後出現，第 6 課則顯示全套課程已完成。返回首頁、總覽及教案入口放在教師示範模式。
- **每一步都有引導**：活動前列出操作說明與提示，活動後可勾選完成標準並繼續。
- **選做不擋路**：進階或加分活動標為「選做」，可以按「略過選做」繼續。
- **不保存資料**：路線進度只在目前頁面，重新整理會從第一步開始，不保存、不傳送任何學生資料。
- **教師示範模式**：在[教師備課](teacher-resources.html)按「開啟教師示範模式」，再用同一分頁進入課程。各課的路線面板可以直接跳到任一步，也能按「全部展開」一次看到整頁。CodeGame 的關卡與 Python Lab 的單元和練習也會開啟。關閉分頁或按「結束示範」會恢復學生路線。也可在課程網址後加 `?teacher=1`（加 `?route=all` 會直接全部展開）。
- 路線設定在 `lesson-routes.js`，引導程式在 `lesson-route.js`、`lesson-route.css`。

CodeGame 與 Python Lab 也改為單一路線：

- **CodeGame**：學生過關後按「前往下一關」。同一關試 3 次未過會自動打開「關卡提示」，6 次後再給拆解方法。
- **Python Lab**：上課時依畫面的「下一步」練習。取得二星後，可從離堂小檢核前往下一單元，也可選做三星。課程總覽仍可用來開啟已解鎖的單元。

兩者都會跟隨教師示範模式全部開啟，畫面右下角會顯示「教師示範模式」與「結束示範」按鈕。

七、八年級全部 12 課另有頁末「本課自適應練習」：基礎、標準、挑戰三級可自行選擇；同一題首次答錯會給提示，同題第二次仍答錯會顯示詳解並降低下一題難度；連續兩道新題首次答對則提高難度。題目依各課概念重新產生，跳題不算通過，也不鎖住課程。這是規則式的形成性練習，不是 AI 評分或正式成績；作答狀態只存在當前頁面，重新整理即清除，不傳送或保存學生資料。正式評量仍依教案的四級規準，檢視積木程式、資料追蹤和修正說明。

反覆練習時，七年級第 2～6 課的數值實驗、幾何參數與資料分析，以及八年級第 1、3、5 課的清單、加總、搜尋與排序練習，會在進入流程時產生新案例，並可再次產生或切換固定示範。八年級第 2 課保留與積木程式任務一致的《小星星》示範，另可按「再抽一首」練習其他旋律；第 4～6 課的抽籤、洗牌與對決原本就會產生隨機結果。概念題、積木正確流程與教學用公式不隨機更改，避免題意或答案失準。

自適應練習另提供可開關的「專注作答模式」，預設關閉。開啟後，離開分頁或切換視窗滿 3 秒，返回時會更換尚未按過「檢查預測」的題目並清除選擇，維持難度與連續答對紀錄，不扣分；已檢查的題目保留提示或詳解，方便訂正。模式僅作用於頁末自適應練習，不影響課程活動；需要切換分頁查資料時可先關閉。開關狀態與離開時間不保存、不傳送；此功能只是專注提醒，不能可靠防止網頁猴等工具，也不能作為作弊判定依據。

## 使用方式

直接以瀏覽器開啟 `index.html`，或部署至靜態網站服務（例如 GitHub Pages）。教材頁面可離線瀏覽，但外部 CDN 的字型與樣式需要網路連線。

CodeGame 點亮任務保存在 `codegame/`，可開啟 `codegame/index.html`，或在本機預覽開啟 `http://127.0.0.1:4173/codegame/`。它是自行開發的機器人指令解謎遊戲，逐關重現指定 Lightbot Code Hour 保存版本的 20 關地圖、高度、起點、方向與指令容量。支援前進、轉向、跳躍、點燈、P1/P2 程序、遞迴迴圈、單步執行與通關判定。原版嵌入頁保留在 `codegame/lightbot.html`。

學生姓名、學號、班級顯示在遊戲上方；草稿、通關、最佳指令、嘗試次數與學習時間依班級及學號保存於此瀏覽器，重新整理後可繼續練習。可下載包含學生資料、遊戲狀態及指令的 PNG，或匯出學習紀錄 JSON。尚未提供登入驗證與資料庫同步。後續可透過 `window.LightbotLearning.setStudent(...)` 更新學生，透過 `exportData()` 及 `codegame:progress` 事件取得紀錄；詳細規則、來源與資料介面見 [CodeGame 說明](codegame/README.md)。

Python Lab 是獨立課程，可從首頁「其他課程」開啟；Python Lab 頁面本身不連回首頁，`pythonlab/` 仍可單獨部署。可將 `pythonlab/` 單獨部署；本機執行 `npm run preview`（或 `node scripts/preview.cjs`）後，開啟 `http://127.0.0.1:4173/pythonlab/index.html`。Python 執行環境固定使用 Pyodide 0.27.7，首次載入需網路。草稿、預測、離堂說明與挑戰驗證只保存在此瀏覽器，不跨裝置同步。詳細教學流程與維護方式見 [Python Lab 說明](pythonlab/README.md)，課程規劃見 [Python 課程設計](PYTHON_COURSE_PLAN.md)。

Python 的十二個單元依序為輸出、變數與輸入、型態與運算、條件、for 累加、巢狀迴圈、while、清單、函式與模組、購物結帳專題、資料排序、字典票選統計。每課包含示範、引導、初階一星、進階二星與選做終極三星，以及語法卡、逐層提示與離堂檢核。一星允許參考完整解答，二星需修改規則並通過新測資，完成核心學習；三星不強制。既有通過紀錄保留為一星。

## 技術概況

- 七、八年級共用情境設定 `course-scenarios.js`，預設仍為星際版。共用頁首、總覽、範例下載路徑、清單資料與部分專題用語可集中替換，不必改動教學規則。新增情境的步驟及仍需同步調整的教材見[課程情境切換指南](COURSE_SCENARIOS_GUIDE.md)。
- 兩個第 6 課的網頁動畫、教案、學習紀錄和簡報位置列入 `course-materials.json`；可執行 `npm run check:materials`，詳細對照與待同步事項見[課程資源清單](COURSE_MATERIALS_GUIDE.md)。
- 靜態 HTML、CSS、原生 JavaScript 為主
- 使用 Tailwind CSS、Lucide、Font Awesome 等 CDN 資源
- `1150801.html` 使用 React 與 Babel 的瀏覽器端版本
- `learning-guides.js` 顯示逐課目標與完成證據；`curriculum-labs.js` 提供課綱補強互動活動；`adaptive-practice.js` 提供不保存作答資料的三級自適應練習
- 僅七年級第 1、2 課部分通關狀態以瀏覽器 `localStorage` 保存；網站不記錄全站成績，也沒有作業繳交後端
- Python Lab 另以 `localStorage` 保存自身的練習草稿與挑戰驗證；Python 在可停止的 Worker 執行，每次任務使用新的變數命名空間，限制執行時間與輸出量，並提供多組案例驗證。這些是形成性練習，不是正式評分或安全隔離服務。
