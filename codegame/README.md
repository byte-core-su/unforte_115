# CodeGame 點亮任務

自行開發的 HTML/CSS/JavaScript 程式解謎遊戲，入口為 `index.html`。可獨立部署在 GitHub Pages，也可直接開啟；建議以網站網址操作，讓瀏覽器保存資料。遊戲本體無外部依賴，可在載入檔案後離線操作。

## 關卡與規則

完整重現使用者指定的 [Lightbot Code Hour 保存版本](https://archive.org/details/lightbot-codehour)所選的 20 個可玩關卡：基礎 8 關、程序 6 關、迴圈 6 關。地圖、空洞、高度、目標、起點、方向、主程式與程序容量均來自該保存版本的 `LevelsDict.levelsHOC15`，不是以其他年度解答推測。畫面、機器人造型與執行程式獨立製作，未附原版 SWF、程式碼、圖片或音效。原版嵌入頁保留在 `lightbot.html` 供對照。

`source-levels.json` 保存逐關校對常數與來源 SHA-256；`levels.js` 將步幅 7 的原始地圖轉為二維陣列。原始 `botx` 是列、`boty` 是欄，`startr` 是方向（0 東、1 南、2 西、3 北）。`leveltypes` 的 6 是空洞、1 是點燈目標。官方教學背景見 [原作者資源](https://lightbot.com/resources.html)。不同年度版本的部分關卡不一樣，本專案以指定保存檔為準。

前進要求相同高度；跳躍可上升一層或下降任意層，相同高度不能跳。遇到邊界、空洞或不符高度時停留原位，繼續下一個指令。點燈切換目標亮暗，全部目標亮起立即過關。P1、P2 執行後返回呼叫處，也允許互相呼叫、呼叫自己。執行上限 10,000 步，避免無窮迴圈。

## 操作與保存

- 參考原版配置，地圖與指令集中在同一個遊戲區；執行／暫停、單步與重設位於指令格上方，速度在指令區標題旁。關卡提示和操作說明可展開查看；拖放刪除區只在拖曳時出現，不推擠程式格。
- 可把指令圖卡直接拖到主程式／P1／P2，拖曳時浮動圖卡跟隨游標並標出插入位置；原有卡片會滑動讓位。程式放滿時，拖入新的指令圖卡會替換目標格，跨程序搬移至已滿的程序會取消並保留原卡片。
- 也可點選指令格，再點動作；圖卡會飛到目標格並自動選取下一格。點選加入會替換選取格的指令。空位會直接接在已有指令後，不產生等待指令。
- 程式圖卡可拖曳排序、搬到另一個程序或拖到刪除區。放到區域外、按 Esc 或切到背景會取消拖曳。支援滑鼠與觸控，並保留前移／後移與 Delete 的操作方式。
- 支援拖曳排序、前移、後移、刪除、清空本關、執行／暫停、單步執行及旋轉視角。
- 連續執行預設每步 1 秒，也可選慢速 1.6 秒或快速 0.5 秒。移動與轉向會先播放動畫，再留出觀察時間；橘色箭頭、機器人臉部與朝向標示一起顯示轉向，提示列說明轉向前後的方位。
- 地板依深度繪製後，再繪製機器人和方向箭頭。機器人移動到兩格之間或經過高台後方時仍完整可見，跳躍維持高度變化和弧線。
- 「回到起點」只重設機器人與燈，保留草稿和通關紀錄；修改指令也會重新開始執行。
- 依「班級＋學號」分別保存 20 關草稿、目前關卡、通關、首次完成日期、嘗試次數、最佳放置指令數及最佳程式。重新整理會恢復草稿與通關紀錄，執行中的位置會回到起點。
- 只累計頁面可見的停留時間；背景時暫停執行。計時不代表有效操作時間。
- 「下載學習畫面」輸出含學生姓名、學號、班級、地圖狀態、指令與日期的 PNG。「學習紀錄」可下載 JSON 備份。

資料目前只存在同一瀏覽器的 localStorage，不跨裝置同步；清除網站資料會失去紀錄。沒有登入驗證或資料庫，手動學生資料不能視為可信身分。儲存被禁止或容量不足時顯示警示，仍可練習及下載。JSON 目前是匯出備份，尚未提供匯入功能。

## 後續資料庫介面

```js
window.LightbotLearning.setStudent({ name: '學生姓名', studentId: '學生學號', className: '班級', source: '登入學生' });
const data = window.LightbotLearning.exportData();
window.addEventListener('codegame:progress', event => {
    // event.detail 是可送往後端的學生與進度快照；本版本不會傳送。
});
```

後端需依已驗證身分決定可存取的學生紀錄，不能直接信任前端學號。現在提供資料更新／匯出入口，雲端載入、同步、衝突處理與教師查詢仍需後續實作。

## 驗證

執行 `node --test tests/codegame*.test.cjs`。測試逐格比對全部原始關卡資料，並以 20 組獨立通關程式驗證容量與可解性；另外驗證高度、空洞、點燈切換、程序返回、遞迴停止、學生紀錄隔離及儲存失敗。圖卡測試檢查插入、替換、排序與刪除；繪圖測試檢查四個移動方向、四個視角，以及平移、上跳、下跳在跨格前後與中途的繪製順序、位置和跳躍弧線，並涵蓋停止及匯出畫面。通關程式位於 `tests/fixtures/codegame-solutions.json`，不會由遊戲頁載入。
