LESSON 4

魔法變數：螺旋圖騰

電腦不僅能做重複的事，還能透過「變數」記住不斷變化的數值。讓我們結合變數與重複結構，畫出向外擴散的漸變螺旋！

1

第一階段：挑戰手動繪製螺旋方形

A 挑戰：組裝手動螺旋積木 (不使用重複迴圈)

螺旋的特性是「每一次畫的邊都要比上一次更長」。在不使用重複執行積木的情況下，我們必須手動依序增加長度！請將下方 7 塊積木拖曳或點選排列，由小到大（10 ➔ 20 ➔ 30 ➔ 40 點）組裝好我們的探測車路線！

B 參考：程式 Pseudo Code 

// 手動繪製四邊螺旋方形，每一步都在長大
畫筆設定
下筆
前進 10 點 ➔ 右轉 90 度
前進 20 點 ➔ 右轉 90 度
前進 30 點 ➔ 右轉 90 度
前進 40 點
停筆

2

第二階段：變數與重複結構的魔法

A 挑戰：用「變數與迴圈」簡化並畫出無限螺旋

剛剛手動寫了好多行程式碼，如果要畫 40 個邊，程式碼會長到看不完！這時就是「重複迴圈」搭配「變數」登場的完美時機！請將 4 塊核心積木排入重複框中，讓線條利用變數自動長大，最後停筆。

B 參考：程式 Pseudo Code 

// 變數初始化
下筆
變數 長度 設為 0

// 螺旋核心邏輯 (使用重複執行簡化代碼)
重複執行 ( 40 ) 次：
  變數 長度 改變 10
  移動 變數 長度 點
  右轉 90 度
停筆
