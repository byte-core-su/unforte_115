# Python Lab 進度同步資料使用說明

本擴充功能服務 Python Lab 教材網站，將各單元通過的星級、通關日期、通關當時的累計時間、總學習時間及最近練習位置，保存至此 Chrome 個人資料的 `chrome.storage.sync`。

資料會依 Chrome 的帳號、同步設定與連線狀況同步到其他已安裝相同擴充功能的電腦。同步傳輸及帳號管理由 Google Chrome 處理。擴充功能在此電腦另存待傳備份，以便重試。

完整程式碼、預測、離堂說明、班級、座號與姓名保存在教材網站的本機儲存空間。擴充功能同步資料不含這些欄位，也沒有廣告或分析追蹤。擴充功能只在指定教材網址與本機 Python Lab 預覽網址建立連接。

使用公用電腦時，請確認 Chrome 個人資料屬於自己。首次啟用時，可選擇載入既有 Chrome 進度，或確認後合併這台電腦的舊進度。教師示範及共用測試紀錄應保存在教師自己的 Chrome 個人資料。

教材網站的本機草稿可在 Chrome 網站資料設定中清除。Chrome 帳號與同步資料由 Chrome 的個人資料及同步設定管理。
