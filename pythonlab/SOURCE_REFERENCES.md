# 參考小幫手的資料來源與取捨

學生所需內容隨網站載入，查詢不會呼叫搜尋服務、載入外部文章、嵌入影片或開啟新分頁。小幫手的分類為本課語法、語法字典、Scratch 對照、常見錯誤、編碼工具、延伸概念。以下為教師與維護者的來源紀錄。

| 原始資料／網站 | 本系統的運用與查閱狀態 |
| --- | --- |
| `data/class-01.txt`～`class-10.txt` | 已閱讀並重整成十個漸進單元。原文保留；用詞、例子與難度依學生程度調整。 |
| [Python.org](https://www.python.org/) | 已參考藍黃品牌方向；目前改為淺藍、奶油黃、白色，以減少大面積深色。 |
| [Python 官方教學](https://docs.python.org/3/tutorial/)與[內建函式說明](https://docs.python.org/3/library/functions.html) | 查核語法與 ord、chr、bin、hex 定義；整理為中文說明與自行編寫範例，來源 URL 保存在字典資料中。 |
| [RapidTables 轉換工具](https://www.rapidtables.org/zh-TW/convert/number/ascii-hex-bin-dec-converter.html) | 已查閱轉換介面，取其字元與進位轉換需求，在本站自行實作。清楚區分 ASCII、Unicode 碼位與 UTF-8 位元組，未搬用外部表格或程式。 |
| [STEAM／Oxxo Label](https://steam.oxxostudio.tw/category/python/tkinter/label.html)、[Button](https://steam.oxxostudio.tw/category/python/tkinter/button.html) | 已查閱標籤、按鈕與事件概念；整理為本地 Tkinter 延伸說明、原創桌面範例及網頁事件示意。網頁示意不宣稱執行 Tkinter。 |
| [SimpleLearn 運算子文章](https://simplelearn.tw/python-for-beginners-tutorial-operators/) | 嘗試讀取但逾時，未宣稱已讀取全文。課程運算解說依原始教材與 Python 官方資料查核後自行整理。 |
| [Scratch](https://scratch.mit.edu/) | 本次未查閱網站；Scratch 對照以提供的原始教材與既有積木觀念整理。 |
| [Trinket](https://trinket.io/python)、[OnlineGDB](https://www.onlinegdb.com/online_python_compiler)、[Colab](https://colab.research.google.com/?hl=zh-tw)、[Jupyter](https://jupyter.org/) | 本次未逐站查閱內容、未嵌入服務。以本站編輯、輸入、執行、驗證功能滿足課程需求；小幫手介紹工具用途與執行狀態差異。 |
| [Animation vs. Coding 影片](https://www.youtube.com/watch?v=EFmxPMdBqmU) | 未觀看，未摘要影片內容；從學生練習頁移除外連，保留原始教材的連結供教師另行選用。 |

核心十課不要求 Tkinter、Notebook、其他容器與排序；延伸資料主動查閱即可。Python 執行器首次使用需從 CDN 下載 Pyodide；本改版不宣稱整個網站完全離線。
