學生操作說明

  1. 選一個單元，先從「示範」開始

    先閱讀任務；程式已經放好，可以直接試跑，不必從空白開始。「示範 → 引導 → 初階 → 進階 → 終極」是建議順序。

  2. 在「程式區」修改，在「輸入資料」準備回答

    程式區放 Python 程式。「輸入資料」每一行對應一次 input()，網站已預填範例；遇到 input() 不用在執行結果裡打字。不需輸入的題目會另外提醒。

  3. 先執行觀察，再驗證任務
    ▶ 執行程式

    使用你填的輸入資料試跑，觀察下方結果。執行成功還不會得星。

    ✓ 驗證任務

    使用本站多組測資檢查，不使用輸入區。全部通過才算完成任務；初階以上才計星。

  4. 失敗時，先看第一個失敗案例

    比較預期輸出與你的輸出，或依錯誤行號修正，一次改一處再試。不知道語法時，使用題目提示與「參考小幫手」，查完回到同一題。

  5. 取得一星後，就能領證並繼續升星

    初階可參考完整解答；二星需要修改新規則；三星為選做。通過新星級會開啟班級、座號、姓名表單，按「顯示通關證書」後擷圖。當天或之後都能繼續挑戰，升星後更新證書。

每題保留自己的草稿。時間按單元累計，可手動暫停；背景分頁與證書畫面暫停計時。草稿、星級與資料只保存在此瀏覽器，換裝置不會自動帶過去。
