while 迴圈簡介
在 Python 中，while 迴圈用於當指定條件為真時重複執行一段程式碼塊。當你需要根據某個條件重複執行動作時，while 迴圈非常有用。基本語法
Python 中 while 迴圈的基本語法如下：

while 條件:
# 當條件為真時要執行的程式碼塊

只要條件保持為真，迴圈將繼續執行程式碼塊。當條件變為偽時，迴圈結束，程式繼續執行迴圈後的下一行程式碼。

範例1.讓我們看一個簡單的例子，使用 while 迴圈從 1 到 5 印出數字：

count = 1
while count <= 5:
     print(count)
     count += 1

在這個例子中：
我們初始化一個變數 count 為 1。
while 迴圈檢查 count 是否小於或等於 5。
如果條件為真，則執行迴圈內容，印出 count 的當前值。
印出後，我們將 count 的值加 1（count += 1）。
當條件 count <= 5 變為偽時，迴圈停止執行。
無限迴圈
使用 while 迴圈時要小心，因為如果條件永遠不變為偽，可能會導致無限迴圈。例如：

範例2.  # 無限迴圈
while True:
       print("這是一個無限迴圈！")

在這個例子中，條件 True 總是為真，所以迴圈將持續執行，不斷印出「這是一個無限迴圈！」。使用 break 和 continue
你可以使用 break 陳述句提前退出 while 迴圈，使用 continue 陳述句跳過迴圈的其餘程式碼塊，開始下一次迴圈。

範例3. 

使用 break 陳述句提前退出 while 迴圈

count = 1
while count <= 10:
     if count == 5:
            break # 當 count 為 5 時退出迴圈
     print(count)
     count += 1

在這個例子中，當 count 為 5 時，迴圈將退出。

範例4. 使用 continue 陳述句跳過迴圈的其餘程式碼塊，開始下一次迴圈

count = 0
while count < 5:
      count += 1
      if count == 3:
           continue # 當 count 為 3 時跳過迴圈其餘的程式碼塊
      print(count)

在這個例子中，當 count 為 3 時，continue 陳述句被執行，跳過該迴圈的 print(count) 陳述句。
