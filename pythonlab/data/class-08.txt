在 Python 中，有幾種常見的陣列資料結構，其中最常見的是列表（List）和元組（Tuple）。除此之外，還有其他第三方庫提供的陣列資料結構，比如 NumPy 的陣列。這裡是它們的簡要介紹：：
列表是 Python 中最基本的資料結構之一，它是一個有序的、可變的容器，可以儲存任意數量的元素，並且可以包含不同類型的元素。列表使用方括號 [] 定義，並且元素之間用逗號分隔。
元組與列表相似，也是有序的容器，但不同之處在於元組是不可變的，一旦創建就不能修改。元組使用圓括號 () 定義，並且元素之間用逗號分隔。
字典是一種鍵值對的資料結構，用於將鍵映射到值。字典使用花括號 {} 定義，每個鍵值對由鍵和值之間用冒號 : 分隔，鍵值對之間用逗號分隔。
NumPy 是 Python 中用於科學計算的重要庫之一，它提供了一個名為 numpy.array 的多維陣列資料結構，這種陣列比原生的列表更有效率，特別是當處理大型數據集時。NumPy 陣列有許多內置的數學和統計函數，用於進行向量化操作。
集合是另一種常見的資料結構，它是一個無序的、不重複的元素集合。集合使用花括號 {} 定義，並且元素之間用逗號分隔。
：
這些都是 Python 中常見的陣列資料結構，每種都有自己的特點和用途。


這裡是一些使用Python中列表的基本示例：

創建一個列表：
my_list = [1, 2, 3, 4, 5]
fruits = ['apple', 'banana', 'orange', 'grape'] 
mixed_list = [1, 'apple', True, 3.14]

存取列表元素：
print(my_list[0]) # 輸出: 1 
print(my_list[2]) # 輸出: 3

修改列表元素：
my_list[1] = 10 
print(my_list) # 輸出: [1, 10, 3, 4, 5]

添加元素到列表：
my_list.append(6) 
print(my_list) # 輸出: [1, 10, 3, 4, 5, 6]

刪除列表中的元素：
del my_list[2] 
print(my_list) # 輸出: [1, 10, 4, 5, 6]

切片列表中的元素：
fruits = ['apple', 'banana', 'orange', 'grape'] 
slice_fruits = fruits[1:3]
print(slice_fruits) # 輸出：['banana', 'orange']

列表中的長度:
fruits = ['apple', 'banana', 'orange', 'grape'] 
length = len(fruits) 
print(length) # 輸出：4

列表檢查:
fruits = ['apple', 'banana', 'orange', 'grape'] 
print('banana' in fruits) # 輸出：True 
print('watermelon' not in fruits) # 輸出：True

列表在Python中是非常靈活和常用的資料結構，它可以容納各種類型的數據，並且支持各種操作，如索引、切片、添加、刪除等。

選擇排序法（Selection Sort）是一種簡單直觀的排序演算法。它的工作原理是這樣的：
1.先從未排序的原始資料中找到第一個最小的元素，將它加到已排序數列的第一項。 
2.接著從未排序的原始資料中找到最小的元素。 
3.將此元素加到已排序數列的最後一項。 
4.重複第 2、3 點的步驟，直到原始資料全部處理完成。
