# Python Lab

適合已有 Scratch 基礎的國中生，共 12 單元、60 個活動。原教材保存在 `data/`；課程以 `course-data.js` 與 `challenge-data.js` 的內容為準。

## 開啟課程

這是獨立課程，直接開啟 `pythonlab/index.html` 的網站網址即可使用，不經過原教材首頁。頁面只提供 Python 課程總覽、十二個單元與參考小幫手，不與原有 Scratch 課程互相導連，也不依賴上一層的樣式檔。可將 `pythonlab/` 目錄單獨部署至靜態網站（例如 GitHub Pages）。維護者本機可在專案根目錄執行 `npm run preview`（或 `node scripts/preview.cjs`），再開啟 `http://127.0.0.1:4173/pythonlab/index.html`，不需安裝額外套件。

首次進入單元會從 jsDelivr 載入固定版本的 Pyodide 0.27.7。尚未載入時可閱讀、編輯；失敗時會提供重試。Python 不支援直接雙擊 HTML 的開啟方式。

## 教學流程

學生首頁提供「選單元 → 修改程式 → 執行後驗證 → 領證再升星」四步操作路徑，可由首頁或頂部「操作說明」重看完整流程。每題練習區有下一步提示，依載入、試跑、錯誤、驗證失敗或通過更新，提供直接前往程式區、輸入區、提示、小幫手、失敗案例、下一題及證書的按鈕。試跑及驗證回饋也附上下一步按鈕。提示不限制操作順序，不要求學生一定先試跑才可驗證；修改程式後不沿用舊程式的成功／失敗提示。示範與引導不計星，執行成功不等於通關；初階以上全部測資通過才會取得星級。閱讀操作說明與小幫手仍算本單元學習時間。

1. 閱讀本課目標、Scratch 對照與概念。
2. 在「示範」先預測，再執行既有程式。
3. 在「引導」修改或補上關鍵邏輯；每個活動保留獨立草稿。
4. 在「★ 初階」參考解答並完成驗證，取得一星；修改規則或功能通過「★★ 進階」取得二星，完成本課核心學習。
5. 二星後解鎖「★★★ 終極・選做」，可自由決定是否挑戰；三星不影響課程核心完成。
6. 完成離堂說明，下載自己的 `.py` 作品。

「參考小幫手」包含本課語法、29 個語法條目、Scratch 對照、11 種常見錯誤、字元與進位轉換工具及延伸概念。查閱與分類切換留在同一頁，回到練習時保留草稿與游標。小幫手不查詢外站，也不嵌入影片。資料來源與查閱狀態見 SOURCE_REFERENCES.md。示範、引導與初階的完整解答需主動展開；一星允許參考完整解答，並保留參考紀錄。二星與三星提供起始程式、提示及語法，不在學習介面展示完整解答。星級不代表獨立完成或正式成績。

輸入區採預先提供資料：每行對應一次 `input()`。以 `-1` 結束的題目必須提供停止值。按「驗證任務」不使用輸入區，會執行固定案例；二星與三星的資料題另外加入六組新產生的測資。測試涵蓋題目所定義的正常、極小、極大、門檻、空資料與無效範圍，異常輸入文字及缺少資料在第 10、11、12 課終極任務明確要求。第一課輸出題採固定格式及實際 print 呼叫檢查，不產生輸入測資。逐課數量、範圍與維護測試見 [測資涵蓋說明](VERIFICATION_COVERAGE.md)。

程式、輸入、預測與離堂說明保存在此瀏覽器，沒有帳號或跨裝置同步。修改草稿後需重新驗證；首頁的進度保留曾通過的星級，分別顯示二星完成單元數與總星數。更新前的通過紀錄轉為一星，既有草稿保留。課內星級依序解鎖，單元間不鎖定。桌面總覽每行三單元，共四行；全課二星完成數為 12，最多 36 星。新增單元保留原 1～10 的編號與草稿鍵，原有星級、累計時間與證書接續保存。可下載 `.py`；還原起始程式與重設全課紀錄均有確認視窗。

## 計時與通關證書

每個單元有獨立累計學習時間，涵蓋閱讀、示範、引導與各星級挑戰；同單元切換活動不重設。進入單元自動計時，可手動暫停／繼續。返回總覽、切換單元、背景分頁、關閉頁面與開啟證書時停止累計；查閱站內小幫手仍計時。每五秒及操作時保存，重新整理或隔天回來接續；瀏覽器意外終止可能遺失最後五秒。手動暫停也保留至重新按「繼續計時」。

首次通過各星級，自動開啟班級、座號（1～999）、姓名表單；一星也可領證。顯示證書後表單隱藏，呈現單元、學生資料、最高星級、取得日期時間與當時累計時間，供擷取畫面。學生資料只保存在本機，下一單元預填最近使用的資料，各單元證書分別保存姓名資料。可隨時從單元「查看通關證書」重開或修改。尚未取得一星時不提供通關證書。

領證不終止或鎖定挑戰；當日或之後皆可繼續升星，取得新星級後自動開啟新版證書。證書時間固定在最高星級首次通過時，重看證書、重驗同級或較低級不改變它。升星後更新累計時間與取得日期。沒有每日重設、截止或挑戰次數限制。舊星級沒有時間紀錄，顯示「未記錄」；舊單元升星則標註僅包含計時功能啟用後的練習時間。重設本機學習紀錄也清除時間及證書資料。這些資料不依學生帳號分開，沒有跨裝置同步；班級與姓名表單不會建立帳號或切換學生進度。

## 十二個單元

1. 從積木到文字：輸出、引號、註解。
2. 讓程式記住回答：變數、輸入。
3. 文字還是數字：型態轉換、運算。
4. 程式做選擇：條件、布林、縮排。
5. 固定次數的重複：for、range、累加。
6. 迴圈裡還有迴圈：巢狀迴圈、九九乘法。
7. 何時停止重複：while、break、停止值，continue 在字典與概念中介紹。
8. 一次處理多筆資料：清單、索引、加總、平均。
9. 把程式整理成工具：函式、參數、return、math。
10. 購物結帳小幫手：整合清單、函式、迴圈與條件。
11. 把資料排出順序：內建排序、前三筆、選擇排序（選做）。
12. 班級票選統計員：字典、無效票、整理空白、平手與無有效票。

排序與字典由原教材第 8 篇擴充為單元 11、12；tuple、set 與 Tkinter 整理在小幫手的延伸區；對獎與影片保留原始教材供教師選用，不作核心課程先備要求。

## 維護與驗證

- `course-data.js`：課程、起始程式、解答、測試與字典。
- `extension-course-data.js`：第 11、12 單元的五階活動、範例與解答。
- `challenge-data.js`：進階與終極任務、固定邊界案例與額外測資產生器。
- `verification-data.js`：逐課補充測資、獨立期望值計算、密集測試用案例及函式回傳檢查資料。
- `progress.js`：星級計算、逐級解鎖與舊紀錄遷移。
- `learning-record.js`：單元計時、學生資料檢核及證書星級快照。
- `operation-guide.js`：逐題下一步建議、試跑與驗證狀態判斷。
- `helper-data.js`：本地錯誤排查與延伸參考。
- `encoding.js`：本地 ASCII／Unicode 碼位與 UTF-8 位元組轉換。
- `app.js`：路由、編輯器、草稿、查詢、回饋。
- `python-worker.js`：載入與執行 Python，與頁面溝通。
- `runner.py`：每組案例建立新命名空間，捕捉輸出與錯誤，比較結果。
- `pythonlab.css`：淺藍、奶油黃、白色與響應式版面。

教材使用輸出測試、函式直接呼叫與部分語法結構檢查，不要求程式文字與解答相同。函式需回傳正確型態：字串 "5" 不等於數值 5，字串 "None" 不等於 None。數值容許相對誤差 1e-9、絕對誤差 1e-12；非有限數值不能作為正確數值結果。文字只容許省略最後一次換行，其他空格、空行及順序須符合題目格式。第一課進階與終極會檢查實際 print 呼叫次數及所用參數。這是引導式練習，不是防作弊或完整程式語意驗證。

執行時間上限 8 秒，輸出上限 20,000 字。停止或逾時會終止 Worker，保留草稿，再載入環境。每次執行重新建立學生的變數命名空間；這不是用於執行不受信任程式的伺服器沙箱。核心只使用標準庫，不自動安裝第三方套件。

在根目錄執行 `npm run test:python` 可用本機 Python 檢查教材、字典、邊界與執行器，需 Python 3。`npm test` 同時執行既有教材檢查。啟動預覽後開啟 `http://127.0.0.1:4173/tests/python-browser.html`，可在實際瀏覽器 Python 環境驗證所有範例、案例、字典、錯誤行號、變數隔離與無限迴圈停止。

新增或修改題目時，先更新需求、起始程式、解答，再加入正常及邊界測試；使用者名稱、變數名稱等非必要細節不要綁定。原始教材來源紀錄與參考小幫手條目需同步更新。
