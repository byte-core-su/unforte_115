# Python Lab

適合已有 Scratch 基礎的國中生，共 10 單元、30 個活動。原教材保存在 `data/`；課程以 `course-data.js` 的內容為準。

## 開啟課程

這是獨立課程，直接開啟 `pythonlab/index.html` 的網站網址即可使用，不經過原教材首頁。頁面只提供 Python 課程總覽、十個單元與參考小幫手，不與原有 Scratch 課程互相導連，也不依賴上一層的樣式檔。可將 `pythonlab/` 目錄單獨部署至靜態網站（例如 GitHub Pages）。維護者本機可在專案根目錄執行 `npm run preview`（或 `node scripts/preview.cjs`），再開啟 `http://127.0.0.1:4173/pythonlab/index.html`，不需安裝額外套件。

首次進入單元會從 jsDelivr 載入固定版本的 Pyodide 0.27.7。尚未載入時可閱讀、編輯；失敗時會提供重試。Python 不支援直接雙擊 HTML 的開啟方式。

## 教學流程

1. 閱讀本課目標、Scratch 對照與概念。
2. 在「示範」先預測，再執行既有程式。
3. 在「引導」修改或補上關鍵邏輯；每個活動保留獨立草稿。
4. 在「挑戰」完成骨架，按「驗證任務」測試多組資料。
5. 完成離堂說明，下載自己的 `.py` 作品。

「參考小幫手」包含本課語法、23 個語法條目、Scratch 對照、10 種常見錯誤、字元與進位轉換工具及延伸概念。查閱與分類切換留在同一頁，回到練習時保留草稿與游標。小幫手不查詢外站，也不嵌入影片。資料來源與查閱狀態見 SOURCE_REFERENCES.md。參考解答需主動展開；展開後完成挑戰驗證，會標示「參考解答後驗證」。這不代表獨立完成或正式成績。

輸入區採預先提供資料：每行對應一次 `input()`。以 `-1` 結束的題目必須提供停止值。按「驗證任務」則使用教材的內建案例，不使用輸入區。

程式、輸入、預測與離堂說明保存在此瀏覽器，沒有帳號或跨裝置同步。修改草稿後需重新驗證；首頁的進度保留曾通過的紀錄。可下載 `.py`；還原起始程式與重設全課紀錄均有確認視窗。

## 十個單元

1. 從積木到文字：輸出、引號、註解。
2. 讓程式記住回答：變數、輸入。
3. 文字還是數字：型態轉換、運算。
4. 程式做選擇：條件、布林、縮排。
5. 固定次數的重複：for、range、累加。
6. 迴圈裡還有迴圈：巢狀迴圈、九九乘法。
7. 何時停止重複：while、break、停止值，continue 在字典與概念中介紹。
8. 一次處理多筆資料：清單、索引、加總、平均。
9. 把程式整理成工具：函式、參數、return、math。
10. 購物結帳小幫手：整合清單、函式、迴圈與條件。

排序、其他容器與 Tkinter 整理在小幫手的延伸區；對獎與影片保留原始教材供教師選用，不作核心課程先備要求。

## 維護與驗證

- `course-data.js`：課程、起始程式、解答、測試與字典。
- `helper-data.js`：本地錯誤排查與延伸參考。
- `encoding.js`：本地 ASCII／Unicode 碼位與 UTF-8 位元組轉換。
- `app.js`：路由、編輯器、草稿、查詢、回饋。
- `python-worker.js`：載入與執行 Python，與頁面溝通。
- `runner.py`：每組案例建立新命名空間，捕捉輸出與錯誤，比較結果。
- `pythonlab.css`：淺藍、奶油黃、白色與響應式版面。

教材使用輸出測試與部分語法結構檢查；數值題容許浮點誤差，不要求程式文字與解答相同。輸出文字題需符合題目格式。這是引導式練習，不是防作弊或完整程式語意驗證。

執行時間上限 8 秒，輸出上限 20,000 字。停止或逾時會終止 Worker，保留草稿，再載入環境。每次執行重新建立學生的變數命名空間；這不是用於執行不受信任程式的伺服器沙箱。核心只使用標準庫，不自動安裝第三方套件。

在根目錄執行 `npm run test:python` 可用本機 Python 檢查教材、字典、邊界與執行器，需 Python 3。`npm test` 同時執行既有教材檢查。啟動預覽後開啟 `http://127.0.0.1:4173/tests/python-browser.html`，可在實際瀏覽器 Python 環境驗證所有範例、案例、字典、錯誤行號、變數隔離與無限迴圈停止。

新增或修改題目時，先更新需求、起始程式、解答，再加入正常及邊界測試；使用者名稱、變數名稱等非必要細節不要綁定。原始教材來源紀錄與參考小幫手條目需同步更新。
