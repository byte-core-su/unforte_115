## 各級公平範圍

- 引導與一星測試題目要求的合法輸入及輸出；完整參考解答仍可通過一星。
- 二星逐步加入範圍限制、空資料及有效性檢查。第九課還直接呼叫函式，避免只在主程式檢查參數。
- 三星依題目增加整合考驗；第 10、11、12 課明確要求處理非整數、空白和缺少資料，這些才納入其驗證。
- 前幾課保證數字輸入的題目，不要求提前學習 try／except。沒有輸入的固定輸出題不重複灌入等價測資，改以錯誤程式測試輸出及語法判定。
- 停止值之後的多餘資料應忽略，不因尚未消耗整個輸入區而判錯。
- 數字合法寫法依 Python 的型態轉換規則，例如有正負號、前後空白及 Unicode 十進位數字，不能一概誤判為無效。

## 判定方式

期望值在 JavaScript 依題目規格計算，未執行學生程式或參考解答來製造答案。加總、秒數及幾何量使用獨立公式；大型整數平方使用 BigInt，避免 JavaScript 數值格式或精度造成誤判。

文字保留空格與空行，只容許省略輸出最後的一次換行，並統一 Windows 換行。數值容許相對誤差 1e-9、絕對誤差 1e-12；NaN／Infinity 不能當作正確數值輸出。函式直接呼叫會檢查實際回傳值：數值字串、布林值及字串 "None" 不能冒充數值或真正的 None。失敗案例與失敗的函式呼叫優先顯示，包含參數、預期回傳與實際回傳，方便先定位問題。

明訂 for、while、巢狀迴圈等概念的題目保留語法結構檢查；list() 與清單生成式也可被辨識為清單；dict() 與字典生成式也可被辨識為字典。第一課 print 的檢查記錄實際執行，未執行的示意程式不能補足 sep／end 要求。各組測試從新的學生變數空間開始；所有組別完整回傳且通過才取得星級。

## 維護回歸

`node --test tests/python-verification.test.cjs` 額外執行 **13,506 組密集及種子情境**，包括 64 組固定隨機種子。小型有限範圍可全列舉，例如 0～100 成績及 1～12 的列欄組合；大型範圍採密集樣本加上下限與代表性區間。這些維護案例不全部放進學生驗證，避免不必要的等待與過長回饋。

另有 **73 個刻意錯誤的解法**，涵蓋48個引導與星級活動：漏加、整除、門檻等號、錯用且或、初始化與更新、索引、停止值、回傳型態、數量、筆數及未處理 EOFError；新單元另檢查排序方向、前三筆、原清單保留、計票累加、無效票、空白整理、平手與零票；每個都必須被測資擋下。**27 組執行器回歸**確認換行、空格、浮點精度、非有限輸出、回傳型態、print 紀錄和替代寫法。完整指令是 `npm run test:python` 或 `node --test tests/python-*.test.cjs`。

啟動預覽後，`tests/python-browser.html` 在實際 Pyodide 環境執行目前 **1,311 組教材與字典案例**、17組執行器回歸、錯誤行號、輸入不足、變數隔離、輸出限制、手動停止及8秒逾時後重新啟動。測資數量會隨教材更新而變動，以測試輸出的實際數量為準。

有限測試無法列舉所有文字與浮點輸入。新增題目規則時，應同步補上規格、邊界案例及能代表該缺口的錯誤解法。
