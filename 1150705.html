LESSON 5

幾何曼陀羅 (進階參數函式)

如果我們為函式加上一個「參數 N」，這個函式就能像變魔術一樣，你給它數字 3 它就畫三角形，給它 5 它就畫五邊形！讓我們逐步將繪圖邏輯打包，最終讓主程式變得極度簡潔！

1

第一階段：定義「畫一個正N邊形」函式積木

A 挑戰：封裝多邊形繪製邏輯

請將含有參數 N的積木正確組合起來，創造出一個能動態決定「邊數」與「轉角」的 「定義畫一個正N邊形 (N)」 萬用函式！

B 參考：參數化函式定義 

// 定義一個吃「參數 N」的萬用函式
定義 畫一個正N邊形( N ): 
  重複執行 ( N ) 次:
    移動 50 點
    右轉 360 / N 度

C 函式威力測試機

🔒 請先完成 A 區的函式定義，即可解鎖測試機！
2

第二階段：呼叫函式！組裝曼陀羅主程式

A 挑戰：曼陀羅主程式組合

現在我們有了 畫一個正N邊形 (N) 這個強大的工具！請將下方的 5 塊積木排好，透過下筆、重複迴圈與呼叫函式 (傳入參數 5)，並加上旋轉，最後停筆，畫出一個完美的五邊形曼陀羅！

B 參考：主程式 Pseudo Code 

// 只要改變呼叫時的參數，就能畫出曼陀羅
下筆
重複執行 ( 12 ) 次: 
  呼叫 畫一個正N邊形( 5 )
  右轉 ( 30 ) 度
停筆

C 主程式執行模擬

🔒 請先完成 A 區的曼陀羅主程式
3

第三階段：再進化！定義「畫幾個圖形 (X)」函式

A 挑戰：封裝曼陀羅的旋轉迴圈

剛才在主程式中「重複呼叫與旋轉」的動作，其實也可以打包成一個新函式！請組裝帶有參數 X的函式積木，專門用來畫出由 X 個正方形（傳入參數 4）所組成的圖騰。

B 參考：雙層函式的威力 

// 定義負責畫出 X 個圖形的第二層函式
定義 畫幾個圖形( X ): 
  重複執行 ( X ) 次:
    呼叫 畫一個正N邊形( 4 )
    右轉 360 / X 度

第五階段：進階彩虹曼陀羅

既然我們已經有了層層分明的函式結構，如果想讓曼陀羅變色，該把「筆跡顏色設為隨機」積木放在哪裡呢？沒錯！就放在「畫幾個圖形(X)」這個第二層函式的迴圈內！這樣每次畫新圖形前就會變色。
